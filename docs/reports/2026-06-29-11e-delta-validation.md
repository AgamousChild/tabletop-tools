# 11e → 10e Delta Validation (2026-06-29)

This report is **regenerated by `apps/brain/server/scripts/validate-11e-delta.ts`**.
Run it after every faction-pack ingest pass to refresh the per-faction counts.

## How to regenerate

```bash
cd apps/brain/server
# Prereqs:
#   1. .local/brain/nodes/*.json exist — run `npx tsx src/build-graph.ts` first
#   2. TURSO_DB_URL / TURSO_AUTH_TOKEN are set (or .local/dev.db is migrated)
npx tsx scripts/validate-11e-delta.ts
```

The script overwrites this file in place with the latest per-faction summary.
It also writes the raw JSON report to
`.local/brain-input/validation-11e-deltas.json` (gitignored — not committed).

## What the report contains

When regenerated, the body of this file is populated with:

- The total number of `(10e ↔ 11e)` matched pairs across all 29 faction packs.
- The number of pairs whose structured fields differ (`content`, `cpCost`,
  `cost`, `when`, `target`, `effect`, `turn`, `phase`, `dp`,
  `forceDisposition`, `modelRestriction`, `isUpgrade`, `isEpicHero`,
  `targetKeywords`).
- A per-faction table — slug, matched, with-delta — sorted by delta count
  descending.

## Method

The parser runs with `edition='11th'` forced (independent of the URL-prefix
heuristic in `detectFactionPackEdition`). Every emitted node is matched
against the local R2 cache for a 10e node with the same
`(factionId, category, slugify(title))`. Field-level deltas are reported
from `validation-delta.ts::fieldsDiffer`.

Out of scope for the parser-side validator: BSData-derived datasheets and
weapons, MFM costing, and Wahapedia unit abilities. Those have their own
delta pathways inside `merge-sources.ts` (e.g. MFM points override at
step 4c, the `updatedInEleventh` bit-flag at step 4d).

## Companion bit-flag

For every 10e node that matches an 11e companion in the merged graph,
`merge-sources.ts` step 4d sets `Node.updatedInEleventh: true`. The brain
build run prints the count under `MergeStats.updatedInEleventhFlagged`.
UI consumers read this flag to render a "Changed in 11th" badge on 10e
cards — display work is filed separately.
